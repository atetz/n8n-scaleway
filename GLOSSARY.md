# n8n on Scaleway

A personal, self-hosted n8n installation on a single Scaleway VM, rolled out in two stages: infrastructure, then provisioning.

## Language

**Setup**:
One complete n8n installation: its VM, IPs, security group and running containers, all identified by one name prefix.
_Avoid_: Environment, stack, deployment

**Name prefix**:
The string that every resource in a Setup is named with, so that one Setup's resources can be told apart from another's.

**Infrastructure stage**:
The first stage, which creates the cloud resources a Setup needs, up to a running, hardened VM that the Deploy user can reach over SSH.
_Avoid_: Deploy, bootstrap

**Provisioning stage**:
The second stage, which configures the running VM and starts n8n, Postgres and Traefik on it.
_Avoid_: Deploy, configuration management

**State bucket**:
An existing Object Storage bucket that holds the OpenTofu state for a Setup. It is created by hand before the first run.
_Avoid_: Backend bucket

**SSH allowlist**:
The IPv4 and IPv6 address ranges that may open SSH connections to the VM. Everyone else is blocked on port 22.
_Avoid_: Whitelist, admin IPs

**Editor allowlist**:
The IPv4 and IPv6 address ranges that may reach the n8n editor and API. Webhooks and forms stay public whatever the list contains, and by default the list allows everyone.
_Avoid_: IP whitelist, IP_WHITELIST

**Deploy user**:
The non-root account on the VM that the operator and the Provisioning stage log in as. Root cannot log in over SSH.
_Avoid_: Admin user, ansible user

**Secrets file**:
The gitignored `.env` file on the operator's machine that holds every secret value of a Setup, for both stages. It never goes into the repository.
_Avoid_: Vault, credentials file

**Settings**:
The non-secret configuration values of a Setup, kept in the repository.
_Avoid_: Env, config

**Encryption key**:
The secret n8n uses to encrypt saved credentials. It is always supplied from the Secrets file, never generated by n8n, and it must match the key of any Dump that is imported.

## Data

**Dump**:
A custom-format (`pg_dump -Fc`) export of an n8n Postgres database.
_Avoid_: SQL file, export

**Backup**:
A Dump of a Setup's own database, taken on a schedule and stored in the Backup bucket.
_Avoid_: Snapshot

**Backup bucket**:
The Object Storage bucket that holds a Setup's Backups and deletes them once the retention period has passed.

**Dump import**:
An optional step in the Provisioning stage that loads a Dump into a Setup's empty database, for example a Backup or a Dump from an earlier install.
_Avoid_: Restore, migration
